# engines/
Motores científicos PUROS: sem FastAPI, sem banco, sem I/O. Recebem dados (incluindo valores de referência com procedência) e devolvem resultados com metadados de proveniência.
- crystallography/: B/core + recursos da A v1.4 (ligas, temperatura, planar, supercélula) refeitos com testes
- hea/: grandezas analíticas citáveis; modelo preditivo só com fonte (Q-01)
- thermodynamics/: dilatação, Lindemann, diagramas de fase (A/docs/2_*)
- machine_learning/: reservado; vazio até haver modelo e dataset validados
